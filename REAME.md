# Проект PythonProject_widget
Виджет, который показывает несколько последних успешных банковских операций клиента.
## Описание:
PythonProject_widget - это учебный вариант виджета, который показывает несколько последних успешных банковских операций клиента.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/ArhPavel/Project_Sky_pro_public.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Использование:

1. Откройте приложение в вашем веб-браузере.
2. Создайте новый проект и начните добавлять задачи.
3. Назначайте сроки выполнения и приоритеты для задач, чтобы эффективно управлять проектами.

## Функционал:
1. decorators.py - файл с функциями - декораторами для логирования
2. external_api.py - файл с запросом api для конвертации валюты онлайн.
3. generators.py - файл с генераторами 
4. masks.py - файл с маскировкой номера карты
5. processing.py - файл с фильтрацией по дате и значению
6. transaction_reader.py - считывает данные из файла json и выводит данные
7. widget.py - виджет для преобразования данных в скрытые данные
8. search_operation -фильтрация и поиск по значению операций с выводом
