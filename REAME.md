# Проект Project_sky_pro_coursework
Курсовая работа
## Описание:
PythonProject_widget - Приложение для анализа и визуализации личных финансовых транзакций на основе данных из Excel-файла.
Проект разделен на независимые слои, реализует веб-представления, аналитические сервисы и автоматическое формирование отчетов с логированием результатов.

## Установка:

1. Подготовка окружения и зависимостей:
Убедитесь, что у вас установлены pandas, openpyxl (для работы с Excel), requests и pytest.bash :
```
Установка необходимых библиотек
pip install pandas openpyxl requests pytest

```
2. Настройка конфигурации:
```
В корневом каталоге проекта создайте файл настроек user_settings.json для отслеживания интересующих активов:
json
{
  "user_currencies": ["USD", "EUR"],
  "user_stocks": ["AAPL", "AMZN", "GOOGL"]
}
Поместите вашу выписку по карте в папку data/operations.xlsx.

```
## Использование:

Для запуска генерации веб-страницы, работы сервисов и автоматического сохранения отчетов выполните команду:
bash
python -m src.main


## Функционал:
1. Веб-страницы (views.py):
1.1 Страница «Главная»: формирует комплексный JSON-ответ на заданную дату. Рассчитывает приветствие по времени суток, агрегирует расходы и кэшбэк (1 рубль на 100 рублей трат) отдельно по каждой карте, выводит ТОП-5 транзакций месяца и подтягивает актуальные курсы валют/акций.
2. Сервисы (services.py):
2.1 Выгодные категории кэшбэка: агрегирует расходы за выбранный месяц и год, высчитывая потенциальный доход.
2.2 Простой поиск: регистронезависимый поиск транзакций по вхождению подстроки в категорию или описание.
2.3 Поиск переводов физлицам: интеллектуальный фильтр на регулярных выражениях, извлекающий переводы вида Имя Ф. в категории «Переводы».
3. Отчеты (reports.py):
3.1 Декоратор @report_logger: автоматически сохраняет результат функции (Pandas DataFrame) в формате JSON. Поддерживает вызов без параметров (имя файла по умолчанию) и с параметром (кастомное имя).
3.2 Траты по категории: анализирует расходы по выбранной категории ровно за 3 месяца назад от опорной даты.
3.3 Траты по дням недели: рассчитывает средний чек расходов на каждый день недели за последние 3 месяца.
